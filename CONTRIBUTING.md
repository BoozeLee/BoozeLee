# Contributing to Bakery-street-project

Thank you for your interest in contributing! This document provides guidelines and instructions for contributing to any of the repositories under the Bakery-street-project organization.

## Code of Conduct

By participating, you are expected to uphold the values of respectful collaboration, constructive feedback, and professional communication.

## How to Contribute

### Reporting Bugs
- Use the [Bug Report](https://github.com/BoozeLee/BoozeLee/issues/new?template=bug_report.md) template
- Include reproduction steps, expected behavior, and environment details
- Check existing issues before opening a new one

### Suggesting Features
- Use the [Feature Request](https://github.com/BoozeLee/BoozeLee/issues/new?template=feature_request.md) template
- Describe the use case and proposed solution
- Consider opening a discussion first for large changes

### Pull Requests
1. Fork the repository and create your branch from `main` or `master`
2. Make your changes with clear, descriptive commit messages
3. Ensure the code follows the project's style guidelines
4. Add tests for new functionality
5. Update documentation as needed
6. Submit a PR using the [PR template](.github/PULL_REQUEST_TEMPLATE.md)

### Development Setup
- Use the language-appropriate tooling (npm, pip, cargo, etc.)
- Follow existing project structure and conventions
- Run tests and linters before submitting
- Keep PRs focused and reasonably sized

## Style Guidelines
- Write clean, readable code with meaningful names
- Add comments for complex logic, not obvious statements
- Update READMEs when changing functionality
- Use consistent formatting (enforced by CI where configured)
